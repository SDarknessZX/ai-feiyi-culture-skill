# 提示词配置说明

所有模型提示词都保存在 `prompts/`，`server/promptLibrary.js` 负责读取、组合并绑定到模板。不要把完整提示词写到前端。

## 非遗换装

民族服饰提示词：

```text
prompts/costume/miao.txt
prompts/costume/yi.txt
prompts/costume/dong.txt
prompts/costume/tibetan.txt
prompts/costume/uyghur.txt
prompts/costume/mongolian.txt
```

华夏朝代提示词：

```text
prompts/dynasty/song.txt
prompts/dynasty/dunhuang.txt
```

模板名称、提示词文件映射和 WebP 展示图路径位于 `server/promptLibrary.js`：

- `costumeEthnicItems`
- `costumeEthnicPromptFiles`
- `costumeDynastyItems`
- `costumeDynastyPromptFiles`
- `costumeImageMap`

人物参考图提示词修改 `buildCostumeReferencePrompt()`；视频统一约束修改 `buildCostumeVideoPrompt()`。

## 萌系美食

固定系统提示词位于：

```text
prompts/food/food.txt
```

后台会把该文件和用户图片一起提交给多模态语言模型，再把模型输出的完整提示词和同一张用户图片提交给 Seedance。

轮播展示内容在 `server/promptLibrary.js` 的 `foodShowcaseTemplates` 中配置，只需要 `title` 和 `imageUrl`。

## 画作动起来

统一提示词位于：

```text
prompts/painting/paint.txt
```

年画、唐卡、剪纸和壁画目前共用该提示词。模板列表及展示图路径在 `paintingMotionTemplates` 中配置。

## 展示图片

展示图统一放在：

```text
public/templates/
```

项目只使用 WebP 文件。新增或替换图片后，同步修改 `server/promptLibrary.js` 中对应的 `/templates/*.webp` 路径。

## 验证

```powershell
npm.cmd run lint
npm.cmd run build
```

开发服务运行时，修改 `server/` 或 `prompts/` 中的文件会自动重启后端。
